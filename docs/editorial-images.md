# Редакционная фотосерия, 30 сентября 2026

Создана встроенным imagegen по предоставленным портретам сотрудницы. Основной стиль: photorealistic-natural, горизонтальный кадр 3:2, мягкий дневной свет, светлое дерево, нейтральный интерьер, тёмно-синяя форма и голубые перчатки. Без текста и логотипов.

Финальные ассеты: `public/images/editorial/`.

- kitchen.webp — уборка столешницы; по просьбе владельца немного уменьшен объём бёдер.
- floor.webp — мытьё пола; слегка скорректирован силуэт.
- windows.webp — мойка окна; лицо повторно скорректировано по портретам 666.jpg и 333.jpg.
- bathroom.webp — полировка смесителя.
- equipment.webp — инвентарь.
- interior.webp / living-before.webp — гостиная в одном ракурсе, изменены только бытовые загрязнения.
- hall-after.webp / hall-before.webp — прихожая в одном ракурсе, следы обуви и пыль.

Промпты правок сохраняли освещение, мебель, перспективу и рабочую позу; для пар просили менять только чистоту поверхностей. Это иллюстрации, не документальные отчёты о выполненных заказах. Исходные PNG сохранены генератором, веб-копии сжаты Sharp в WebP, ширина 1440, качество 84.

Два дополнительных варианта в закрытом спортивном купальнике предназначены для отдельного просмотра и не включены в публичные страницы.
